## 📸 Features
- Ingredient-based Search
- Diet Filters (Vegan, Gluten-Free)
- Cuisine Filters (Italian, Indian etc)
- Nutrition Info & Calories
- Cooking steps & time
- Favorites / Bookmark system
- User Login & Register
- Personalized Recommendations

## 🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript
Backend: Node.js, Express.js
API: Spoonacular API
Database: MySQL
Design: ER Diagram, DFD, UML Diagrams

## ⚙️ How It Works
1. Search Module - User input to API params
2. Recipe Management - Fetch & display recipes
3. User Management - Auth & bookmarks
4. Recommendation Engine - Suggest based on history
