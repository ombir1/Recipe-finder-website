# 🍲 Recipe Finder Website

A full-stack web application to discover recipes using the Spoonacular API.

## 📸 Features

- Ingredient-based Search
- Diet Filters (Vegan, Gluten-Free)
- Cuisine Filters (Italian, Indian, etc.)
- Nutrition Info & Calories
- Cooking Steps & Time
- Favorites / Bookmark System
- User Login & Register
- Personalized Recommendations

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** Node.js, Express.js
- **API:** Spoonacular API
- **Database:** MySQL
- **Design Docs:** ER Diagram, DFD, UML Diagrams

## ⚙️ How It Works

1. **Search Module** — Takes user input and converts it into API parameters
2. **Recipe Management** — Fetches and displays recipes from Spoonacular
3. **User Management** — Handles authentication and bookmarks
4. **Recommendation Engine** — Suggests recipes based on user history
